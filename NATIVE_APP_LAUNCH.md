# Native App Launch Plan

The HomeOS India customer and technician product will now be implemented as a mobile application for Android and iOS. It will use native-safe layout, role-specific mobile navigation, camera/gallery capture for issues and job proof, and location-aware job tracking. No existing mobile scaffold is available in the workspace, so a dedicated Expo project is required. The API contract remains supported by the full-stack service foundation, while browser tools are reserved for internal operations.

The first app build will focus on the full AC-not-cooling demo lifecycle: customer dashboard, Fix Anything diagnosis, technician selection, quote approval, completion OTP, payment state, 30-day warranty, and Home Service Passport update.
